# 示例数据说明

本目录仅含**少量脱敏示例**，用于演示输出格式。**完整数据集不公开**。

| 文件 | 说明 |
|---|---|
| `事件_示例.xlsx` | 事件表（表头 + 前 8 行，24 列，与目标模板逐列一致） |
| `事件评论信息_示例.xlsx` | 评论表（表头 + 前 50 行，4 列：ID / 评论者 / 内容 / 点赞数） |
| `事件图_示例/` | 3 张示例配图（命名 `P{n}-{n}-{k}.jpg`） |

完整数据集的规模（供参考）：**163 个话题 / 109 个完整事件 / 6852 条评论 / 126 张配图**。

字段含义与口径说明请见根目录 [`README.md`](../README.md) 的「数据表结构」与「数据质量与口径」两节。

> ⚠️ 示例中的评论内容来自公开微博，仅用于格式演示；请勿用于其他用途。
